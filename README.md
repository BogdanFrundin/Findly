# FINDLY

Кликабельный прототип FINDLY — AI-поиска одежды по магазинам Украины.

20 экранов: поиск словами и по фото, карточка товара со сравнением цен, вишлист для подарков, готовые образы, слежение за ценой, профиль и подписка PRO.

## Как открыть

Откройте `index.html` в браузере. Сборка и установка не нужны.

## Статус

Прототип: товары, цены и наличие примерные. Настоящие товары появятся после подключения фидов партнёрских сетей (Admitad и другие).
